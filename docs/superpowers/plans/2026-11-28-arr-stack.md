# Video automation (*arr) stack: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a Docker Compose *arr stack inside the Jellyfin LXC (pve CT 200, 10.0.0.10). It turns a Seerr request into a hardlinked, subtitled file in Jellyfin, and all torrent traffic is forced through Proton WireGuard.

**Architecture:** gluetun owns the network namespace. qBittorrent joins it (`network_mode: service:gluetun`), so it has no route except the tunnel. Prowlarr, Sonarr, Radarr, Bazarr and Seerr use the normal Docker bridge. Every container mounts host `/media` at `/data`, which keeps hardlinks on one filesystem. The compose file lives in the repo at `lxc/jellyfin-arr/` and is deployed by copy (`scp` + `docker compose up -d`).

**Tech Stack:** Proxmox `pct`, Docker CE + compose plugin (Ubuntu 24.04), gluetun v3.41.3, linuxserver.io images, Seerr (the renamed Jellyseerr), Jellyfin 10.11.6 (existing, native).

**Spec:** `docs/superpowers/specs/2026-11-28-arr-stack-design.md`

## Global Constraints

- **Host:** CT 200 on pve (10.0.0.2). The LXC is unprivileged with `nesting=1,keyctl=1`. Memory 4096 → 8192 MB.
- **Ownership:** all containers use `PUID=107`, `PGID=110` (jellyfin:jellyfin), `TZ=Asia/Seoul`, and the volume `/media:/data`.
- **Images, pinned by tag:**
  - `qmcgaw/gluetun:v3.41.3`
  - `lscr.io/linuxserver/qbittorrent:5.3.1_v2.1.3-ls490`
  - `lscr.io/linuxserver/prowlarr:3.1.0.5799-ls170`
  - `lscr.io/linuxserver/sonarr:4.0.20.3014-ls7`
  - `lscr.io/linuxserver/radarr:7.0.3.10918-ls328`
  - `lscr.io/linuxserver/bazarr:v1.6.2-ls374`
  - `ghcr.io/seerr-team/seerr:v3.5.2`
- **Ports (LAN only):**

  | Service | Port | Notes |
  |---|---|---|
  | qBittorrent | 8080 | published on gluetun |
  | Prowlarr | 9696 | |
  | Sonarr | 8989 | |
  | Radarr | 7878 | |
  | Bazarr | 6767 | |
  | Seerr | 5055 | |

- **Never committed and never printed:** `/opt/arr/gluetun/wg0.conf` (0600, already in place, JP#153, NAT-PMP on).
- **Seeding:** stop at ratio 1.0 or 7 days (10080 min). Sonarr/Radarr minimum free space is 50 GB (51200 MB).
- **Library rules:** Sonarr renaming stays **off**, so existing folder names never change. `/media/english` is never touched.
- **Jellyfin libraries today:** `/media/anime`, `/media/shows`, `/media/english`. `downloads/` is outside all of them and must stay that way.

## Review Focus

1. **Tunnel drops mid-download.** qBittorrent must lose connectivity, not fall back to the LAN route. Covered by Task 2, Step 6.
2. **The WireGuard conf has IPv6 lines, but Docker has no IPv6.** gluetun must still connect over IPv4 instead of crash-looping. Covered by Task 2, Step 4, with the strip-IPv6 fallback.
3. **The forwarded port changes after a reconnect.** qBittorrent's listen port must follow it. Covered by Task 2, Step 7 (restart gluetun, then compare the ports).
4. **An import would cross filesystems.** It must be a hardlink (same inode), not a copy. Covered by Task 6, Step 3.
5. **Existing root-owned anime and shows folders.** Sonarr must be able to write there, and Jellyfin must still read them after the permission change. Covered by Task 3, Step 2 plus Step 6.

### Task 2: gluetun + qBittorrent with a verified kill switch

**Files:**
- Create: `lxc/jellyfin-arr/compose.yaml`
- Create: `lxc/jellyfin-arr/README.md`

**Interfaces:**
- Consumes: Docker and the TUN device from Task 1, and `/opt/arr/gluetun/wg0.conf`.
- Produces: qBittorrent WebUI at `10.0.0.10:8080` with user `admin`. The password is saved in Vaultwarden as "qBittorrent (arr)". qBittorrent's listen port tracks the Proton-forwarded port.

- [ ] **Step 1: Write `lxc/jellyfin-arr/compose.yaml`** (VPN services only for now; Task 3 appends the rest)

```yaml
# Deployed to /opt/arr/compose.yaml in pve CT 200 (jellyfin, 10.0.0.10). Not Argo-managed:
#   scp lxc/jellyfin-arr/compose.yaml root@10.0.0.10:/opt/arr/ && ssh root@10.0.0.10 'cd /opt/arr && docker compose up -d'
# Spec: docs/superpowers/specs/2026-11-28-arr-stack-design.md
x-common: &common
  restart: unless-stopped
  environment: &env
    PUID: "107"   # jellyfin
    PGID: "110"   # jellyfin
    TZ: Asia/Seoul

services:
  gluetun:
    image: qmcgaw/gluetun:v3.41.3
    restart: unless-stopped
    cap_add: [NET_ADMIN]
    devices: [/dev/net/tun:/dev/net/tun]
    environment:
      TZ: Asia/Seoul
      VPN_SERVICE_PROVIDER: custom
      VPN_TYPE: wireguard
      VPN_PORT_FORWARDING: "on"
      VPN_PORT_FORWARDING_PROVIDER: protonvpn
      # Push the forwarded port into qBittorrent (WebUI has "bypass auth for localhost" on).
      VPN_PORT_FORWARDING_UP_COMMAND: >-
        /bin/sh -c 'wget -qO- --retry-connrefused --post-data
        "json={\"listen_port\":{{PORTS}},\"random_port\":false,\"upnp\":false}"
        http://127.0.0.1:8080/api/v2/app/setPreferences'
      FIREWALL_OUTBOUND_SUBNETS: 10.0.0.0/24
    volumes:
      - /opt/arr/gluetun/wg0.conf:/gluetun/wireguard/wg0.conf:ro
    ports:
      - "8080:8080"   # qBittorrent WebUI

  qbittorrent:
    <<: *common
    image: lscr.io/linuxserver/qbittorrent:5.3.1_v2.1.3-ls490
    network_mode: service:gluetun   # no route except the tunnel = kill switch
    depends_on:
      gluetun: { condition: service_healthy }
    environment:
      <<: *env
      WEBUI_PORT: "8080"
    volumes:
      - /opt/arr/config/qbittorrent:/config
      - /media:/data
```

```bash
ssh root@10.0.0.10 'cd /opt/arr && docker compose restart gluetun && sleep 40 && docker compose up -d qbittorrent && sleep 15
```

Expected: the port from the `port forwarded is NNNNN` log equals `"listen_port":NNNNN`. Note that `curl` from inside the CT reaches qBittorrent through the published port, so the source is not localhost and you must use a cookie. If the call returns `Forbidden`, use the login cookie from above.

- [ ] **Step 5: Import existing series into Sonarr (no file moves, renaming off)**

```bash

QP=$(curl -s -H "$H" $S/qualityprofile | jq '.[]|select(.name=="HD-1080p").id')
TAG=$(curl -s -H "$H" $S/tag | jq '.[]|select(.label=="anime").id')
for root in anime shows; do
  ssh root@10.0.0.10 "ls /media/$root" | while read -r d; do
    hit=$(curl -s -G -H "$H" --data-urlencode "term=$d" $S/series/lookup | jq -c '.[0] // empty')
    [ -z "$hit" ] && { echo "UNMATCHED $root/$d"; continue; }
    type=$([ $root = anime ] && echo anime || echo standard); tags=$([ $root = anime ] && echo "[$TAG]" || echo "[]")
    echo "$hit" | jq --arg p "/data/$root/$d" --arg t "$type" --argjson qp "$QP" --argjson tags "$tags" \

  done
done
```
